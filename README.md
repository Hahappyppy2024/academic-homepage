# Academic homepage

Static bilingual academic website. No build step is required.

## GitHub Pages

1. Create a GitHub repository. For a personal homepage, name it USERNAME.github.io using your real GitHub username.
2. Upload the contents of this folder to the repository root. index.html must be at the root, alongside assets/ and .nojekyll.
3. In Settings > Pages, choose Deploy from a branch, main, and /(root), then Save.
4. Open the published URL shown by GitHub Pages and verify the site.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

The contact form opens the visitor's email application to send a message. It does not store messages on a server.

Edit assets/profile.js to update personal information and publication status. Keep bundled font license files.
